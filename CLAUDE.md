# Project Rules
- Always invoke the `frontend-design` skill before writing or editing UI code.
- **Aesthetic Direction:** Swiss editorial minimalism mixed with tactile developer craft. Clean, high-contrast typography, generous whitespace, and subtle interactive details.
- **Anti-Patterns (STRICTLY AVOID):** Do NOT use generic SaaS hero sections, purple/blue gradients, multi-column icon grids, progress bars for skills, or boxy drop-shadow cards.
- **Tech Stack:** Next.js (or Astro/Vite), Tailwind CSS, Lucide Icons, and Framer Motion for subtle micro-interactions.
